# Quinta do Coelho

Site institucional da **Quinta do Coelho**, espaço de eventos localizado em Encourados, Barcelos, Braga.

## Sobre

Quinta rústica e tradicional do Minho, disponível para casamentos, batizados, comunhões, festas de aniversário, eventos empresariais e muito mais.

**Contacto:** 964 605 331  
**Localização:** Encourados, Barcelos, Braga
